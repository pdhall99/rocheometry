# Citation

If you use Rocheometry in published work, please cite it using its Zenodo DOI, [10.5281/zenodo.24325522](https://doi.org/10.5281/zenodo.24325522), which always resolves to the latest release.

Please also state the version you used, given by `rocheometry.__version__`.
Each version has its own DOI, listed on the [Zenodo record](https://doi.org/10.5281/zenodo.24325522).

```bibtex
@software{rocheometry,
  author    = {Hall, Philip D.},
  title     = {Rocheometry},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.24325522},
  url       = {https://doi.org/10.5281/zenodo.24325522},
}
```

For a specific release, Zenodo's record page gives a BibTeX entry with that release's DOI and version.
In AAS journals, also name Rocheometry in the `\software{}` statement.

The citation metadata is also in [`CITATION.cff`](https://github.com/pdhall99/rocheometry/blob/main/CITATION.cff), which GitHub uses for its **Cite this repository** button.
